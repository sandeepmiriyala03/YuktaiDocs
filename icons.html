    Use an icon

    React / Next.js

    1. npm install @yuktishaalaa/yuktai
    2. Copy the React / Next.js line from the studio. Icon components work in Server Components too.
    app/page.tsx
    import { EyeOffIcon } from "@yuktishaalaa/yuktai/icons"

<EyeOffIcon size={40} color="#084d31" label="Hide password" />
<EyeOffIcon size={40} color="#084d31" variant="filled" shape="circle" />

    Plain HTML

    1. Add the YuktAI script once, before </body>.
    2. Copy the Plain HTML code from the studio; it fills a placeholder with the SVG.
    index.html
    <span id="my-icon"></span>
<script>
  document.getElementById("my-icon").innerHTML =
    yuktai.icon("eyeOff", { size: 40, color: "#084d31", strokeWidth: 2.5, label: "Hide password" })
</script>

    No script? Use Copy SVG and paste it into your HTML, or use the downloaded file in an <img> with a meaningful alt.

    Add label when the icon means something on its own; leave it out when the text next to it says the same, so screen readers don't repeat it. Icons need 3:1 contrast with their background (WCAG 1.4.11); the studio checks it for you.
