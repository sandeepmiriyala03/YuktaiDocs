Rust engines

Rust engines

YuktAI has two optional engines written in Rust and compiled to WebAssembly: grid search and number/date sorting, and the page RAG search. They return exactly the same results as TypeScript, only faster on big data. Time them here on your own sizes.

How the engines work

Small and self-contained

The Rust code is no_std, compiled to WebAssembly and embedded in the YuktAI script as base64. There is no extra file to host, no bundler setting, and it works offline.

Same results, proved

Rust runs the same rules as TypeScript (Unicode-aware tokens, prefix matching, BM25 with the same idf), and parity tests check that every query returns the same rows and passages in the same order.

Safe fallback

The engine loads only when you set engine. If WebAssembly is missing or blocked, TypeScript runs instead and grid.engine says "ts".

Content Security Policy

Sites with a CSP need 'wasm-unsafe-eval' in script-src for the Rust engines. This site's netlify.toml shows a working policy.
