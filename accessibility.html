Accessibility

Accessibility widget

One floating ♿ button gives every visitor their own settings: contrast, dark mode, text size, a dyslexia-friendly font, colour-blind filters, reduced motion, larger targets and speak on focus. Choices are saved in the browser and restored on every page.

Live demo

Change this page from code

Each button calls yuktai.apply(…). Watch this page change, then reset.

yuktai.getSettings()

app/components/A11yButtons.tsx
"use client"
import { wcagPlugin } from "@yuktishaalaa/yuktai"

// The ♿ button comes from <YuktAIWrapper showAccessibility>. To change
// settings from your own UI, call the engine directly:
export function HighContrastButton() {
  return (
    <button onClick={() => wcagPlugin.execute({ enabled: true, highContrast: true })}>
      High contrast
    </button>
  )
}
app.js
// Settings are saved in localStorage ("yuktai-a11y-prefs"), the same key the npm package uses.
yuktai.apply({ highContrast: true })        // one or more settings
yuktai.apply({ fontSizeMultiplier: 1.2 })   // 0.8 – 1.3
yuktai.apply({ colorBlindMode: "deuteranopia" })
yuktai.getSettings()                        // current settings
yuktai.reset()                              // back to defaults
yuktai.open()                               // open the ♿ dialog
yuktai.openTools("qa")                      // open the 🛠 page tools on a tab
