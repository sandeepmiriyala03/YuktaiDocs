Ask page (RAG)

Ask page (RAG)

Answer questions from your own text, your page and your grid data. YuktAI finds the best passages and quotes them; an optional on-device model can then write the answer from only those passages.

What it is, honestly: BM25 keyword retrieval with prefix matching for word endings and Telugu-aware tokens, in TypeScript or Rust. It is not vector (embedding) search: it finds passages that share words with the question, so an English question will not match Telugu-only text.

Try it with your own text

Paste your FAQ, policy or help text. Each paragraph (separated by a blank line) is one passage.

app/help/AskHelp.tsx
"use client"
import { useMemo, useState } from "react"
import { createContextIndex } from "@yuktishaalaa/yuktai"

const documents = [
  { id: "leave", text: "Leave policy: every employee gets 24 days of paid leave a year." },
  { id: "wfh", text: "Work from home: staff may work from home two days a week." },
]

export function AskHelp() {
  // includePage: true also indexes the visible page text
  const index = useMemo(() => createContextIndex({ documents, includePage: false, engine: "rust" }), [])
  const [answer, setAnswer] = useState("")
  async function onAsk(question: string) {
    const r = await index.ask(question, { k: 4 })   // { answer, hits: [{ id, text, score }], generated }
    setAnswer(r.answer)
  }
  return (/* your input + <p aria-live="polite">{answer}</p> */ null)
}
help.html
<script>
  const index = yuktai.createContextIndex({
    documents: [
      { id: "leave", text: "Leave policy: every employee gets 24 days of paid leave a year." },
      { id: "wfh", text: "Work from home: staff may work from home two days a week." }
    ],
    includePage: false,      // true: also index the visible page text
    // rows, columns, rowKey: also index grid data
    engine: "rust"           // "ts" | "rust" | "auto"
  })

  const r = await index.ask("How many leave days do I get?", { k: 4 })
  r.answer   // quoted from the best passages, nothing invented
  r.hits     // [{ id, source, text, score }]
  index.search("leave days", 3)   // ranked passages only
</script>


Let a model write the answer (optional)


Pass generate to ask. YuktAI sends the model only the question and the top passages, so the answer stays grounded. Chrome's built-in Gemini Nano runs on the device; any API works too.


lib/generate.ts
// Chrome built-in AI (Gemini Nano). Falls back to the quoted answer when it is not available.
export async function generate(question: string, context: string) {
  const LM = (globalThis as any).LanguageModel
  if (!LM) throw new Error("No on-device model")
  const session = await LM.create()
  return session.prompt(
    "Answer only from these passages. If they do not answer it, say so.\n\n" + context + "\n\nQuestion: " + question
  )
}

// const r = await index.ask(question, { generate })   → r.generated === true
app.js
async function generate(question, context) {
  if (!window.LanguageModel) throw new Error("No on-device model")
  const session = await LanguageModel.create()
  return session.prompt("Answer only from these passages.\n\n" + context + "\n\nQuestion: " + question)
}
